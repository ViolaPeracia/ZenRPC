# ZenRPC Assets

This directory contains static assets, documentation, and art resources for ZenRPC:

* [`art_assets/`](art_assets/): Curated 512×512 PNG icons for Discord Rich Presence broadcasting across 58 desktop applications.
* [`art_assets/README.md`](art_assets/README.md): Step-by-step English guide for uploading assets to the Discord Developer Portal.
* [`art_assets/SOURCES.md`](art_assets/SOURCES.md): Complete provenance, license, and upstream source information for each icon.
