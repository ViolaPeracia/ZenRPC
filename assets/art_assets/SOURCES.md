# ZenRPC Art Assets — Provenance & Licenses

This directory contains curated, normalized 512×512 PNG art assets corresponding to each recognized application asset key in ZenRPC.
These assets are intended for uploading to the **Discord Developer Portal** under your application's **Rich Presence → Art Assets** settings.

Every asset has been independently sourced from official brand repositories, permissive open-source vector icon libraries (Simple Icons, SVGL), or Wikimedia Commons (Public Domain / CC0 / Fair Use / Permissive Brand Guidelines).

## Specifications
* **Dimensions:** 512 × 512 pixels
* **Color Depth:** 32-bit RGBA (alpha transparency channel preserved)
* **Format:** PNG with compression optimization
* **Naming Scheme:** Exact match to the `"icon"` key configured in `config.example.json` and `app/config.py`.
